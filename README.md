# Python Programming for Finance

PGE M1 · Fall 2026 · instructor repo

## Setup

Requires [uv](https://docs.astral.sh/uv/getting-started/installation/). Then:

```bash
uv sync
```

Run scripts with `uv run python path/to/script.py`.
